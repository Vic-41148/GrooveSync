# AI Policy

GrooveSync uses AI-assisted tooling in parts of the repository work.

Rules for this repo:
- Do not add AI-generated content to the Flatpak manifest.
- Do not add AI attributions to repo content or commit messages.
- Follow the repo commit rules in `CONTRIBUTING.md` and `AGENTS.md`.

This file exists so the disclosure is in one place when a channel asks for it.
